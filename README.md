# Ticket Booking Transportation System

A Java Swing desktop app for booking bus and ferry tickets between towns in Sabah.

## Features
- User registration and login
- Choose bus or ferry, one-way or round trip
- Pick origin, destination, departure/return date and time, and number of passengers
- Fare calculation (Bus RM15, Ferry RM5 per passenger)
- Simulated card payment

## Run
Requires Java 11 or later.

```
javac test.java
java test
```
